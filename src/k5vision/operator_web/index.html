Choose a camera above, or enter the IP address used to open its settings.

CAMERA ADMINISTRATION

Remove camera?

Live video and new recording will stop. This camera’s history and playback will disappear from the workspace.

This action does not delete recording files. They remain subject to rolling retention. To restore access to retained recordings, connect the camera again with its original name and IP address.

LOCAL CAMERA CONNECTION

Connection help

  1. Confirm the camera is powered on and reachable from this PC. Open its management page using the camera’s IP address.
  2. Enable ONVIF access and an H.264 video stream in the camera settings. Some cameras require a separate ONVIF account.
  3. Select Add camera, then Find cameras on this network. If discovery is blocked, enter the camera’s IP address and camera settings port.
  4. Enter the camera username and password, select Test connection, then choose an H.264 stream. After changing a camera password, select Reconnect camera and test again.
  5. Use current Edge or Chrome. If K5 itself is unavailable, confirm K5 is running on this PC and check its startup message.

Closing the browser does not stop recording while K5 remains running. Live connection failures create gaps in recording history.
